Known gaps & recurring flags

Carried forward, cycle to cycle, exactly as found — never papered over.

SPBM8 Spotted Bear Lookout absent
9 mi from the fire, the best-positioned sensor in the network — still not reporting in any cycle so far.
12Z Aug 1 balloons not yet posted
Great Falls & Spokane checked every cycle since ~13:00Z threshold; both still NO DATA as of cycle11.
Model-run substitution trap
GFS 06Z/12Z Aug 1 and NAM 12Z Aug 1 silently return a stale prior-day run instead of erroring. Caught every cycle by checking embedded metadata.
"GEM" model code is fake
Silently returns byte-identical NAM data — never reported as real GEM output.
SWLM8 Swan Lake temperature bad
Reads ~97°F every cycle, physically implausible — unusable, flagged not fixed.
Badger Pass ridge sensor lag
Wind/temperature channels post roughly 9–10 hrs behind real time, with an intermittent 1-hour offset between the two channels.
Note on file numbering: a separate, more active forecasting effort (Forecast No. 4, issued this cycle, plus ensemble/transect/cross-section analysis) has been running in the same folder and reused the "cycle4" filename — the original observation-only cycle4 content is preserved in this dashboard's chart/table data, but the file on disk now holds that forecast session's own cycle4. Not something this recorder is correcting on its own.
